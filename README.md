This is an upscale of an older project that used an ultrasonic sensor to create 3D scans of its surroundings. I will be using a Neato Botvac DX Series LiDAR scanner and a Raspberry Pi Pico.

As of now, the scanner is capable of 2D scans. The first checkpoint of this project will be to allow the scanner to make 3D scans of the room. 

This is meant to be a learning project. Things I want to gain out of this:

Getting better at Fusion360
Understanding how to use a Raspberry Pi better
Improve Python skills
Improve C
Understand system design
